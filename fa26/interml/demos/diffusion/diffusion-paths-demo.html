Every panel uses the same data, the same noise variance \(\nu\) and the same Brownian increments. Only the drift \(b\) changes.

Reverse time

\[ dX_t = \big[\, b(X_t,t) - \nu\,\nabla \log p_t(X_t) \,\big]\,dt + \sqrt{\nu}\,d\bar W_t, \qquad t: T \to 0 \]

Started at \(t = T\) and integrated back to 0 with the exact score of the selected process. The probability-flow ODE \(\dot x_t = b(x_t,t) - \tfrac12 \nu\,\nabla \log p_t(x_t)\) has the same marginals and no noise.
