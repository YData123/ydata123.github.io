Diffusion processes in two dimensions

\[ dX_t = b(X_t,t)\,dt + \sqrt{\nu}\,dW_t, \qquad X_t \in \mathbb{R}^2,\quad X_0 \sim p_{\text{data}} \]

\(W_t\) is a standard 2D Brownian motion, so each coordinate receives noise of variance \(\nu\,dt\). Both panels use the same data, the same \(\nu\) and the same Brownian increments. Only the drift \(b\) changes.

Forward paths: same noise, two drifts

Particles are coloured by the data mode they started in. Dashed circles mark two standard deviations of each data component. Trails follow 30 particles from \(t=0\). Click a drift to study it below.

Marginal density and score at time t:

Density \(p_t(x)\), scaled to its peak at this \(t\) Arrows show \(\nabla \log p_t(x)\). Length saturates for large scores, and arrows fade where \(p_t\) is negligible.

Reverse time

\[ dX_t = \big[\, b(X_t,t) - \nu\,\nabla \log p_t(X_t) \,\big]\,dt + \sqrt{\nu}\,d\bar W_t, \qquad t: T \to 0 \]

Particles start at \(t=T\) and run back to 0 with the exact score. The probability-flow ODE \(\dot x_t = b(x_t,t) - \tfrac12 \nu\,\nabla \log p_t(x_t)\) has the same marginals and no noise.
